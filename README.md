# LUMIÈRE — Fine Dining Restaurant Website

Lumière is a modern and elegant fine dining restaurant website designed to provide a premium and engaging digital dining experience.

## 🌐 Live Website

https://aminabatool09-hash.github.io/lumiere-restaurant/

## 📌 Project Overview

Lumière is a responsive restaurant website featuring an elegant dark-themed design, premium typography, interactive menu cards, image gallery, customer reviews, table reservation form, special offers, services, and contact information.

The website is designed to provide a smooth and visually appealing experience across desktop, tablet, and mobile devices.

## ✨ Features

- Responsive navigation with mobile menu
- Elegant hero section
- Restaurant story / About section
- Restaurant statistics
- Interactive food menu
- Menu category filtering
- Add-to-cart functionality
- Special weekend offer
- Countdown timer
- Services section
- Responsive image gallery
- Gallery lightbox
- Customer reviews slider
- Table reservation form
- Reservation success message
- Contact section
- Newsletter subscription
- Social media links
- Back-to-top button
- Fully responsive design
